# Space Fishing Art Bible

This file defines the visual and audio direction for Space Fishing so future generated assets stay coherent. Use it before creating fish, UI, ship, station, Codex, or audio assets.

## Overall Visual Identity

Space Fishing is a cozy space-fishing game with a chill Discord ship vibe. The world should feel like a calm shared spaceship where players hang out, fish, collect odd cosmic creatures, and contribute to a shared ship.

Core visual traits:

- Dark space backdrop.
- Soft neon glow.
- Readable shapes and silhouettes.
- Playful alien fish.
- Calm but magical atmosphere.
- Cozy ship lighting rather than harsh sci-fi machinery.

Avoid:

- Realistic fish rendering.
- Painterly fantasy illustration as the default gameplay style.
- Over-detailed sprites that become noisy at small size.
- Random generated-asset style drift.
- Obvious AI slop, mismatched lighting, inconsistent anatomy, or inconsistent material treatment.

The game should feel intentional and cohesive, even while assets are temporary or generated.

## Fish Art Style

Fish should be stylized 2D game-friendly creatures, not realistic wildlife paintings.

Rules:

- Clean silhouette first.
- Slightly cute or chunky proportions.
- Readable at small UI size.
- Transparent background.
- Side view by default.
- Soft neon rim light.
- Limited cosmic detail.
- One iconic gimmick per fish.
- No text inside the asset.
- No scene background behind the fish.

Fish can be weird, alien, and magical, but each fish should still look like it belongs in the same game.

Examples of iconic gimmicks:

- Tiny orbiting moon.
- Comet tail fin.
- Star-map spots.
- Glassy nebula belly.
- Solar flare crest.
- Black-hole ring.

Legendary fish can be more elaborate, dramatic, and intimidating, but they must remain readable and match the same cozy cosmic style. Legendary should feel memorable and scary/exciting, not like a different game's boss illustration.

## Ship / Interior Style

The ship is the long-term social and progression layer. It should feel like a cozy circular spaceship, not a spreadsheet menu.

Ship traits:

- Circular interior layout.
- Dark metal base.
- Soft station lights.
- Warm glows around interactable objects.
- Central fishing hole/core as the focal point.
- Physical stations that read as interactable objects.
- Enough negative space that players can understand where to walk.

Stations should eventually become physical ship objects:

- Gear Bench.
- Reactor Console.
- Deep Space Scanner.
- Tackle Box.
- Codex.
- DEV/debug area for local builds only.
- Future shared Cargo Bay.

Panels should open contextually from stations. The default view should feel like a place, not a dashboard where every system is always visible.

## UI Style

The UI should stay light, readable, and contextual.

Rules:

- Minimal always-on HUD.
- Contextual station panels.
- Clean readable panel backgrounds.
- Soft glow and strong text contrast.
- Clear button states.
- No clutter.
- No permanent dashboard/excel feeling.
- Debug/dev tools should stay hidden or clearly marked.

Use panels for focused interactions such as upgrades, Tackle Box, Codex, scanner, help, or debug. Avoid making the main ship view a wall of text.

## Rarity Visual Language

Rarity should be readable through color, silhouette, glow, and detail level. Rarity should not require noisy decoration.

- Common: simple, cozy, friendly, low-detail, soft colors.
- Uncommon: slightly more colorful or odd, one playful alien twist.
- Rare: stronger glow, clearer cosmic feature, more distinctive silhouette.
- Epic: magical, unstable, dramatic, stronger energy treatment.
- Legendary: cosmic, memorable, scary/exciting, more elaborate, but still readable.

Higher rarity can have more motion, lighting, and anticipation, but the base shape must remain clear.

## Audio Direction

Audio should support the cozy ship mood and fishing feedback without becoming harsh.

Current generated sounds are placeholders. They are acceptable for testing, but they should be curated or replaced later.

Direction:

- Soft UI sounds.
- Cozy ambient ship feel later.
- Gentle fishing hole shimmer.
- Fishing sounds should be satisfying but not sharp or annoying.
- Catch success should feel warm and rewarding.
- Fish escape should be noticeable but not punishing.
- Upgrade purchase should feel like a small ship-system confirmation.
- Legendary warning should feel like a deep cosmic or ship rumble, not an annoying beep.

Avoid loud alarms unless used very sparingly for special moments.
